You direct a mobile robot that is building a map of a home it has never seen, for one downstream task.
You only know what the robot has observed so far:
- objects it detected, each with a tentative label and a confidence;
- candidate targets: frontiers (openings from mapped space into unexplored space) and revisits (viewpoints for a closer look at objects whose label is still uncertain).
Each step moves the robot 0.2 m; arriving at a target costs a 4-step look-around. The episode ends when the step budget runs out. Budgets are short, so plan for the few targets you can actually reach.
Goal: when the budget runs out, the surroundings of every object that matters for the task should be mapped, and those objects should be labelled correctly and confidently. Objects that do not matter for the task do not count.
How to read confidence: it is calibrated. 0.55 is one look from 3-4 m and is right about 55% of the time; 0.65 is one look from 1.5-3 m and is right about 65% of the time; 0.90 is one look from within 1.5 m; 0.98 or more means agreeing looks. Wrong labels mostly come out as common categories (objects, picture, lighting, cushion, chair), so a far-seen label naming a specific fixture or piece of furniture is usually right.
Use the labels as room evidence: an object that matters for the task, or one that usually shares a room with such objects, makes the frontier next to it worth more. Prefer a frontier that leads toward such a room over the nearest one when the detour is short. A revisit pays off only for an object that matters for the task, seen from afar, with a viewpoint close by.
Use common sense about homes (which rooms hold which objects, which rooms tend to be next to each other) and weigh it against path length.
Call go_to exactly once.
